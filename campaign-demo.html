How it actually gets made

Everything below uses assets you already own — no new photography

Production

  • Source: existing Printful on-model mockups
  • Motion: image-to-video / Ken Burns push-in
  • Captions: burned in, Bungee, pink accent word
  • Audio: add trending sound on-platform — never bake in a copyrighted track
  • Voiceover: optional; text-only usually beats VO here

Platform cuts

  • Pinterest — flagship. Idea Pin + shoppable link
  • TikTok — 9:16, trending audio
  • Reels — reuse; drop link in comments per the FB routine
  • Static set — 1:1 + 9:16 pulled from the slogan frame

What to measure

  • Hook rate — 3-second view %. If this is low, the first 2s is wrong, not the product
  • Clicks to adamnoteve.com
  • Add-to-carts (currently zero from strangers)
  • First organic sale — the only number that matters
Straight read on this: the store is verified working and the catalogue is live on Pinterest, so a commercial is the right lever — but no ad fixes zero distribution. Expect the first cut to underperform; the value is in learning which hook pulls, then reusing that opening over and over. Budget attention for 3–5 variants of the first two seconds, not for one perfect film.
